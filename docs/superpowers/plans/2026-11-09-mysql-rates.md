# MySQL 汇率持久化实施计划

目标：使用用户已授权的本机 MySQL92，将手机实际获取的完整汇率列表及更新日期保存到数据库，提供真实查询页面与交作业截图。

方案：Python 标准库 HTTP 服务仅监听 127.0.0.1:8787，使用 MySQL 官方客户端及本机 rate-assignment 登录配置连接数据库。Android 在现有子线程中获取网页后 POST 汇率快照；数据库不可达时保留本地成功结果并明确提示保存失败。当天重新打开应用仍仅读取 SharedPreferences，不再次联网。调试模拟器通过 adb reverse 访问本机接口。APK 与仓库不保存数据库密码。

表结构：rate_snapshots 保存每日快照元数据（日期唯一、来源、更新时间）；currency_rates 保存币种、每 100 外币的人民币报价、列表顺序，关联快照。同一天刷新在事务中替换该日明细；其他日期保留。
