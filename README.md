## 项目介绍

本项目是基于 Android Studio 开发的移动应用项目，项目内容来自《移动技术开发与创业》课程。项目实现了一个简单的 BMI（身体质量指数）计算器，用户输入身高和体重后，点击计算按钮即可得到 BMI 结果，并查看相应的健康建议。

项目使用 Java 和 XML 完成界面与功能开发，并通过 Git 对项目代码进行版本管理和同步。

## 项目功能

1. 输入身高，单位为厘米。
2. 输入体重，单位为千克。
3. 根据公式计算 BMI：

   ```text
   BMI = 体重 ÷ 身高（米）²
   ```

4. BMI 结果保留两位小数。
5. 根据 BMI 数值给出偏瘦、正常、超重或肥胖的健康建议。
6. 对空输入、非数字输入和不合理数据进行提示。
